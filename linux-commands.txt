ls -> listar diretórios da pasta atual
ls / -> (/) lista as pastas do início do sistema de arquivos
ls -l / -> listagem longa, traz mais detalhes da pasta que está

pwd -> (print working directory)  mostra o caminho até o atual diretório

cd <pasta/caminho> -> change directory, acessa o diretório indicado

--- OBSERVAÇÕES IMPORTANTES ---
~ -> indica o diretório inicial, o mesmo que cd /home/nome_usuario

--- PASTAS IMPORTANTES ---
/home -> diretório principal, tem os diretórios principais do usuário
